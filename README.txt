RUNAWAY MULTIPLAYER — обновление названия

Название игры изменено на Runaway. Мультиплеер:
- До 10 игроков в комнате.
- Автоматический подбор самой заполненной комнаты со свободными местами.
- Создание новой комнаты, если все комнаты заполнены.
- Список активных комнат, ники, синхронизация движения и общий чат.

Обновление Render:
1. Распакуй архив.
2. Замени файлы в GitHub-репозитории этими файлами.
3. Commit и push.
4. Дождись повторного deploy на Render.

Build Command: npm install
Start Command: npm start
